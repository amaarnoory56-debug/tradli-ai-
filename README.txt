TRADLI V12 — REAL AI AGENTS

هذه النسخة تنقل الوكلاء من واجهة شكلية إلى استدعاءات AI فعلية عبر خادم.

المعمارية:
1) المستخدم يرفع 1D + 4H + 1H + 15M.
2) الخادم يرسل الصور إلى نموذج رؤية عبر OpenAI Responses API.
3) يتم تشغيل 12 محللاً مستقلاً بأدوار مختلفة.
4) يتم إرسال نتائج الوكلاء والصور إلى محرك إجماع نهائي.
5) إذا لم تكن المستويات قابلة للاستخراج من الصور، يجب أن تكون النتيجة التريث بدلاً من اختراع أرقام.

الأمان:
- لا تضع OPENAI_API_KEY داخل index.html.
- ضع المفتاح على الخادم فقط في متغير بيئة.
- هذه النسخة لا تنفذ أوامر تداول؛ القرار المعروض تعليمي/تجريبي والتنفيذ يدوي.

التشغيل على VPS:
npm install
انسخ .env.example إلى .env وضع مفتاح API في الخادم
npm start

ثم افتح منفذ 8080 عبر HTTPS/Proxy مناسب.

ملاحظة: تشغيل 12 وكيل + محرك إجماع يعني عدة استدعاءات API، وبالتالي توجد تكلفة استخدام حسب النموذج والحجم.
